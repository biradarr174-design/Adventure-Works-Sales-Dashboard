# Adventure-Works-Sales-Dashboard
Interactive sales dashboard created using Tableau and Power BI using the Adventure Works dataset.
# Adventure Works Sales Analysis

## 📌 Project Overview

This project analyzes the **Adventure Works sales dataset** to understand sales performance, products, customers, and overall business trends.

The project covers the complete data analysis process, starting with **data cleaning using SQL** and ending with **interactive dashboards using Excel, Tableau, and Power BI**.

---

## 🛠️ Tools & Technologies

* **SQL / MySQL** – Data cleaning and data preparation
* **Microsoft Excel** – Data analysis and dashboard creation
* **Tableau** – Interactive data visualization and dashboard
* **Power BI** – Interactive dashboard and business analysis

---

## 🔄 Project Workflow

### 1. SQL – Data Cleaning

SQL was used for preparing and cleaning the data before visualization.

Main activities included:

* Removing unnecessary data
* Handling missing values
* Checking duplicate records
* Cleaning and transforming data
* Selecting required columns
* Preparing data for analysis

---

### 2. Excel – Data Analysis & Dashboard

Excel was used to analyze the cleaned data and create an interactive sales dashboard.

The dashboard includes:

* Sales KPIs
* Sales analysis
* Product analysis
* Customer-related analysis
* Charts and visualizations
* Filters and interactive elements

---

### 3. Tableau – Interactive Dashboard

Tableau was used to create an interactive visualization dashboard.

The dashboard provides:

* Sales performance analysis
* Product analysis
* Customer analysis
* Interactive filters
* Charts and KPIs
* Business insights

🔗 **Tableau Public:** [View Dashboard] https://public.tableau.com/app/profile/shweta.biradar5755/viz/adventureworks_TABLEAU_DASHBOARD/Dashboard1

---

### 4. Power BI – Interactive Dashboard

Power BI was used to create another interactive dashboard using the same Adventure Works dataset.

The dashboard includes:

* Sales KPIs
* Sales performance analysis
* Product analysis
* Customer analysis
* Interactive charts
* Slicers and filters
* Dashboard-level insights
